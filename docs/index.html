🔑 Login to Deal Bot Admin

Paste a GitHub token (only for this repo). It is saved only in this browser — never uploaded anywhere.

How to create the token (1 minute, one time)
  1. Open github.com/settings/personal-access-tokens/new
  2. Name: dealbot-admin · Expiration: whatever you like
  3. Repository access: Only select repositories → choose amazon-deal-bot
  4. Permissions → Repository permissions:
    • Contents: Read and write
    • Actions: Read and write
  5. Click Generate token → copy → paste above

🔗 Link Shortener

Example for Short.io (POST):
URL: https://api.short.io/api/v3/links
Headers: {"authorization":"{key}"}
Body is not supported yet — prefer GET-style APIs or use spoo.me.

ℹ️ Good to know

Amazon's own amzn.to short links cannot be created by bots — Amazon reserves them for its SiteStripe browser toolbar. Full amazon.in links convert best and are 100% safe with Amazon's terms. Short links still contain your affiliate tag — tracking always works.
